데스크톱 모달 규격 가로 480px 고정, 패딩 40px, 코너 곡률 8px. 백드롭은 Ink(#10182B) 컬러의 40% 불투명도 적용. 그림자는 0 24px 64px rgba(16,24,43,.18)의 부드러운 단일 섀도우를 사용합니다.
모바일 바텀시트 변환 폭 390px 뷰포트에서 하단 밀착 바텀시트로 자동 전환. 상단 코너만 12px 라운딩 처리하며, 전화번호 인풋은 모바일 숫자 키패드(`inputmode="numeric"`)가 트리거됩니다.
타이포그래피 및 카피 규칙 Pretendard 서체 기반, `word-break: keep-all` 적용으로 한글 단어 끊김 방지. 지정된 모든 문구(상호명 예시, 약관 상세, 직통 전화 링크)를 오탈자 없이 완벽히 유지합니다.
